# 用户使用指南

## 快速开始

### 启动应用

#### macOS 桌面应用
1. 双击应用图标启动
2. 应用会自动启动后端服务（首次启动可能需要几秒钟）
3. 等待应用界面加载完成

#### 开发模式
参考 [开发指南](../README.md#开发指南)

## 基本操作

### 项目管理

#### 创建新项目
1. 点击左侧边栏顶部的 **"+ New"** 按钮
2. 在弹出的对话框中输入项目名称
3. 点击 **"确定"** 创建项目

#### 切换项目
1. 在左侧边栏顶部的下拉菜单中选择要切换的项目
2. 系统会自动加载该项目的数据

#### 删除项目
1. 确保已选中要删除的项目
2. 点击项目选择器右侧的 **🗑️** 按钮
3. 在确认对话框中点击 **"确定"**
4. ⚠️ **警告**: 删除项目将永久删除所有相关数据，包括剧本、资产、事件等

### 剧本管理

#### 创建集（Episode）
1. 在 **剧本** 视图（左侧导航第一个图标）
2. 点击底部的 **"+ New Episode"** 按钮
3. 输入集标题和剧本内容（可选）
4. 点击 **"确定"** 创建

#### 编辑集
1. 点击集标题或右侧的 **✏️** 按钮
2. 在编辑对话框中修改标题和剧本内容
3. 点击 **"保存"** 保存修改

#### 创建场（Scene）
1. 在某个集下，点击 **"+ Add Scene"** 按钮
2. 输入场标题（例如："草庙村·日"）
3. 输入剧本内容（可选）
4. 点击 **"确定"** 创建

#### 编辑场
1. 点击场标题或右侧的 **✏️** 按钮
2. 在编辑对话框中修改标题和剧本内容
3. 点击 **"保存"** 保存修改

**在剧本视图中编辑场**:
1. 从左侧剧本树中选择一个场
2. 在右侧编辑面板中编辑：
   - **场标题**: 修改场景标题
   - **Action (画面描述)**: 描述场景中发生的动作
   - **Stable Diffusion Prompt**: 输入用于生成图像的提示词
3. 点击 **"保存修改"** 保存

#### 创建镜头（Shot）
1. 在剧本视图中选择一个场
2. 在中间面板中点击 **"+ 加镜"** 按钮
3. 系统会自动创建一个新镜头

#### 编辑镜头
1. 在中间面板中点击要编辑的镜头
2. 在右侧编辑面板中编辑：
   - **镜头名称**: 可选，为镜头命名
   - **Action (画面描述)**: 描述镜头中的动作
   - **Stable Diffusion Prompt**: 输入提示词
   - **状态**: 选择镜头状态（draft/in_progress/done）
3. 点击 **"保存修改"** 保存

#### 删除场或镜头
1. 在剧本树中，点击场或镜头旁边的删除按钮
2. 确认删除操作
3. ⚠️ **注意**: 删除场会同时删除该场下的所有镜头和相关文件

### 资源管理

#### 上传资源到镜头
1. 在剧本视图中选择一个镜头
2. 在右侧编辑面板的 **"Assets"** 区域
3. 点击 **"上传文件"** 按钮
4. 选择要上传的文件（支持图片、视频、音频等）
5. 文件会自动上传并关联到该镜头

#### 上传视频到镜头
1. 在镜头编辑面板的 **"Video Preview"** 区域
2. 点击 **"上传视频"** 按钮
3. 选择视频文件
4. 上传完成后，视频会在预览区域显示

### 资产库管理

#### 查看资产库
1. 点击左侧导航的 **"资产"** 图标（第三个）
2. 在资产库视图中查看所有资产条目

#### 创建资产条目
1. 在资产库视图中点击 **"+ 新建资产条目"** 按钮
2. 输入资产名称
3. 选择资产分类（人设、背景、道具等）
4. 输入描述和基础提示词（可选）
5. 点击 **"确定"** 创建

#### 上传资产文件
1. 在资产条目详情中点击 **"上传文件"** 按钮
2. 选择要上传的文件
3. 文件会自动保存到对应的分类目录

#### 删除资产
1. 在资产条目或资源文件上点击删除按钮
2. 确认删除操作
3. ⚠️ **注意**: 删除资产条目会同时删除所有关联的文件

### 事件管理

#### 创建事件
1. 点击左侧导航的 **"事件"** 图标（第二个）
2. 在事件列表中点击 **"+ New Event"** 按钮
3. 输入事件名称
4. 选择事件颜色（点击颜色圆圈）
5. 点击 **"确定"** 创建

#### 编辑事件
1. 在事件列表中点击要编辑的事件
2. 在编辑面板中修改事件信息
3. 保存修改

## 常见问题

### Q: 应用启动后显示白屏？
A: 
1. 检查后端服务是否正常启动（查看终端日志）
2. 确保 Python 和 uvicorn 已正确安装
3. 尝试重启应用

### Q: 无法上传文件？
A:
1. 检查文件大小是否过大
2. 确保有足够的磁盘空间
3. 检查文件格式是否支持

### Q: 删除项目后数据还在？
A:
1. 删除项目会删除数据库记录和文件
2. 如果文件仍在，可能是权限问题
3. 可以手动删除 `{应用数据目录}/data/{项目名称}/` 目录

### Q: 如何备份项目数据？
A:
1. 复制 `{应用数据目录}/database.db` 文件
2. 复制 `{应用数据目录}/data/{项目名称}/` 目录
3. 恢复时替换相应文件即可

## 数据存储位置

### macOS
- **数据库**: `~/Library/Application Support/com.ljc.aicomictool/database.db`
- **数据文件**: `~/Library/Application Support/com.ljc.aicomictool/data/`

### 开发环境
- **数据库**: 项目根目录 `database.db`
- **数据文件**: 项目根目录 `data/`
