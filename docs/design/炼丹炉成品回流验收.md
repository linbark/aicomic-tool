# 炼丹炉成品回流 · 第二阶段验收

> 2026-11-12。承接[可信基础](炼丹炉可信基础验收.md)。范围仍是独立研究 CLI，不是星晴桌面产品或跨领域审美能力的完成声明。

## 1. 已接通的垂直切片

同一正文/共同条件 → 两颗完整冻结丹药 → 两份编码 agent 实现的真实静态页面 → 引擎受控 Chrome 捕获 → 匿名 A/B 截图包 → 独立视觉评价 → 按配方定义哈希与条件分组的统计。

新增 `experiment create / attach / blind / record / stats`，schema 24。核心实现见[实验与回流](../../inspiration/crates/ie/src/experiment.rs)、[受控捕获](../../inspiration/crates/ie/src/capture.rs)、[迁移](inspiration/migrations/023-artifact-experiments.sql)。

- 实验冻结共同正文、条件、两颗丹药及完整配方定义，后续不从可变配方表重构历史。
- 每臂绑定原 HTML、只读归档、实际 PNG、捕获回执及其哈希；每臂只能导入一次，改页面必须新实验。
- 捕获只使用已有本机 Chrome/Chromium；独立临时 profile、CSP 限制、脚本/外部资源校验、固定 light/DPR 1/视口，不安装软件或启动 HTTP 服务。
- 匿名包严格只有 A/B 两张图、清单和清单哈希；内部映射、材料、丹药、配方和旧分不导出。包中后来添加身份说明文件也会拒绝继续评价。
- 记录前核对原文件、归档、截图、回执、公开包与 manifest；没有截图不能静默回退文字评审。
- 静态检查复用同一冻结规格分析函数，报告与 artifact 绑定，但 `evidence_kind=static_check`、`visual_quality=false`。它不是美感评分。
- 人评须显式 human 和非空 reviewer。默认 demo；注入 renderer 即使冒称 Chrome 也不升级为可信捕获，mock/AI/演示均不进入正式真人统计。
- 同实验/同人/visual 只用最新真人记录，后来的 demo/AI 不能遮盖真人；按实验去重，按完整配方哈希 × 条件哈希 × 固定规则分组。同配方对自己不分胜负。
- 不混用现有文本 `judge` 分、BT 分、`final_total` 或校准，不直接加减药液质量、修改配方比例。

## 3. 回归与真实浏览器诊断

实际通过 **72 个单元/模块行为测试 + 9 个 CLI 集成测试，共 81 个**；同时通过：

```sh
cargo fmt --all -- --check
cargo test --workspace --all-targets --locked --offline
cargo clippy --workspace --all-targets --locked --offline -- -D warnings
cargo build --release --locked --offline
```

关键覆盖包括：缺旧/不完整快照拒绝、两臂一次归档、无图不能盲评、匿名包稳定且无身份信息、所有文件和清单篡改拒绝、缺文/换素材不合规、mock 与真假评分隔离、最新人评与去重、同配方不同条件不混合归因、数据库历史不可覆盖，以及 CLI 的 ID=1 与裸 reviewer 标志不能误解为身份。

真实浏览器回归额外发现：Blink 全局 `scriptEnabled=false` 会同时阻止 Chrome 自身 headless 截图流程，出现退出码 0 但缺 PNG。单变量对照定位后仅移除 Blink 的全局脚本开关，保留页面输入校验和 `script-src 'none'` CSP；本机验证截图成功且页面内联脚本仍被阻止。缺图现在保留错误原因并附有界 stderr 尾，不能只凭退出码成功声称捕获成功。

另修复并行集成测试仅用纳秒时间戳造成临时目录碰撞的问题，增加进程内原子序号。真实模型不进入回归测试；正式统计正向测试只用明确标记的隔离 synthetic fixture，不代表真实用户样本。

## 4. 使用及保留条件

命令与输入示例见[研究 CLI](../../inspiration/README.md)。已有库需显式 `migrate --db <chosen-path>`；本阶段没有静默升级默认库。

原文件、归档和所有登记公开包必须保留原路径；丢失/篡改会拒绝评价，并从正式统计排除。失败 attach 可能留下未注册的只读目录，重试应使用新输出目录，不删除或覆盖未知文件。

## 5. 明确没有证明的事

1. 源码文字/媒体覆盖不等于完整 DOM 可见性；生成配置是操作者声明，不是独立认证；匿名投影不证明评审者此前未见配方。
2. CSP/浏览器参数不是 OS 网络沙箱；哈希不是抗数据库所有者篡改的数字签名。
3. 系统字体与本机环境未完全钉死，不承诺跨平台像素一致；Windows/Linux 和远端 CI 尚未执行。
4. 静态通过不是美感，n=1 不是普遍优劣，不能将本样例包装成严格因果随机实验。
5. 目前只覆盖静态 HTML，不宣称真实交互、视频、动效、跨领域稳定审美或全数据导入导出已经完成。
6. 真人视觉审稿不自动等于个人偏好，也未用于训练个人内核；身份/个人用途确认、真实训练来源隔离、冷启动与内核影响配方，是第三阶段。
