# 炼丹炉原生可视化界面 · 验收

> 2026-11-12。本轮为独立研究引擎增加可用的 Rust / Iced 桌面工作台，不修改星晴根桌面工作流，不使用 WebView、Node 或本地 HTTP 服务。设计依据见[界面设计](炼丹炉可视化界面设计.md)，操作命令见[README](../../inspiration/README.md)。

> **0.1.1 补充（2026-11-13）**：初版遗漏了真实素材库无扩展名哈希文件的预览验证。已修复，真实库 851 张完整解码通过，另 14 条未关联本地图像；183 项回归通过。详见[预览缺失修复](炼丹炉预览缺失修复.md)。下文保留初版验收记录，不把当时演示图通过当作真实库已经全覆盖。

## 可以直接使用

- **素材库**：真实图像网格 / 对象列表、即时搜索、分页、预览、当前与历史药液。
- **炼丹台**：选材 → 本地 palette / spacing 药液 → 配方比例，或选择已有配方 JSON，严格炼制冻结规格；不调用生成模型，不冒充版式 / 字体理解。
- **丹药**：以对象编号区分同名同秒记录；默认展示保存时的配方、组件比例、药液 ID / 修订 / 技术版本、原素材、配色样本、间距数值和规格文字。原始 JSON 可展开；旧记录明确不可重放，不拿今天的药液补历史。
- **结构检查与导出**：显示实际预检、完整度、配比、错误 / 警告；明确不是美感分。Brief 写入全新子目录，不覆盖已有用户文件。
- **我的偏好**：已有匿名 A/B 成品并排审阅，四选及再次确认；身份、真实来源、私人用途、冷启动分开。未填身份不记 human；私人用途默认关闭；体验库在前后端均强制 demo，不创建真人样本，不自动拟合 / 启用内核。

## 原库与异步保护

不传数据库参数时不读取任何默认库；打开已有库一律先只读。只有用户明确另存为工作副本或新库成功后，界面才允许写入。复制通过 SQLite backup，保留 committed WAL，且只迁移新目标；目标已存在或是悬空链接时拒绝覆盖。失败保留源库，必要时选择新目标重试。

素材没有随数据库一起复制。副本保存绝对素材根提示；重新打开时界面在未明确 `--root` 的情况下采用提示并安全重载。明确的 CLI 根目录优先；路径失效显示缺图，不偷偷换来源。跨机器搬迁仍需带上素材并重新指定位置。

读取、动作、图像解码、系统文件对话框、截图编码都在后台执行；generation / config 校验阻止旧结果覆盖新库。图片按可见集合解码为 720px 内预览，缓存受限。操作忙碌时禁写但允许浏览。视觉记录成功但个人桥接失败时，界面保留后端真实消息、来源和失败原因，不泛称个人采集成功。

## 实际验证

独立 workspace 通过 **172 个测试**：131 引擎 / studio 模块测试、11 原 CLI 集成测试、30 桌面状态 / 数据测试。并通过：

```sh
cargo fmt --all -- --check
cargo test --workspace --all-targets --locked --offline
cargo clippy --workspace --all-targets --locked --offline -- -D warnings
cargo build --workspace --release --locked --offline
```

重点覆盖：schema 21–25 只读不改字节、缺库不创建、复制只升级新目标、素材根重开和明确参数优先、实际提炼 ID 钉住而非最大 ID、低对比与非法比例不强炼、Brief 不覆盖、演示 / 个人来源隔离、混合来源 raw 与可用数分开、过期后台结果与确认拒绝、偏好搜索选中对象一致、旧规格不伪补、个人桥接失败如实反馈。

另用[明确的隔离演示生成器](../../inspiration/crates/ie/examples/studio_fixture.rs)实际跑通：新库 → 6 张生成演示图 → 本地提炼 → 两配方丹药 → 两份自包含页面 → 本机受控 Chrome 截图 → 匿名包 → 原生界面读取。生成器类型明确 fixture，不进入正式人评；没有录入真人选择，也未调用付费或真实生成模型。

### 证据 JSON 精度修复

真实双成品回归暴露了 `48 / 13` 静态字号比例在 JSON 往返后发生 1 ULP 的解析误差，使未改变的报告被误判为篡改。先通过 public create → attach(mock) → blind 写回归取得相同失败，再启用 `serde_json/float_roundtrip` 使持久化数字精确恢复。原真实 Chrome 对照与全新端到端示例均重放成功；没有删检查、加 epsilon、改旧证据或把 mock 当受控 Chrome。

## 尚未验证 / 本版不含

- Apple Silicon Mac 本机已验证；Windows、Intel Mac 和远端 CI 未执行，不能据此宣称跨平台验收完成。
- 仅本地 ad-hoc 签名，没有 Developer ID 公证。首次运行如被系统拦截，应由用户从 Finder 右键打开；本轮未改任何系统安全 / 隐私设置。
- Iced 是原生窗口 / GPU 渲染，不是全 AppKit 控件。没有完整自定义 Mac 菜单、NSColor/Increase Contrast 桥接或经过 VoiceOver 验收的辅助功能树。Tab 焦点不能当作所有按钮可键盘操作的完整证明。
- 系统文件选择器已接真实 rfd，状态机选择 / 取消 / 失败路径有回归，但未做人手逐项对话框交互验收；截图不建立这一证明。
- GUI 审阅已有成品实验；新素材采集、创建 / 捕获实验、外部模型设置与内核拟合 / 启用仍沿用 CLI。不是一键生成所有成品或完整 CLI 功能映射。
- 当前本地炼药只覆盖两个像素代理，不是完整语义理解或稳定美学内核。体验数据永不补真实样本门槛。
