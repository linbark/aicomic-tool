# 个人美学内核设计（ToC 层）

> 设计稿 v0.1 ｜ 2026-11-10 ｜ 主设计：[灵感引擎设计](灵感引擎设计.md) ｜ 迁移：[002-personal-layer.sql](inspiration/migrations/002-personal-layer.sql)
>
> 这篇回答一个问题：当引擎面向个人（ToC）而不是机构时，数据模型、学习方式与产品形态该怎么变。核心主张是——**每个人都有自己的美学内核；内核是判断，风格是语言；风格可以借，内核不能让。**

## 0. 一页结论

大多数审美产品的做法是训练一个"大众审美模型"，再把所有人往里塞。结果一定是平均值：安全、正确、没有个性。这条路错在把**共识**当成了**目标**。

正确的关系是：

```text
第一层  公共语料 + 人群先验     「人类大致觉得什么是美的」      共享、可修正
第二层  个人美学内核 δ           「我在所有语境里都不让渡的判断」  私有、跨域不变
第三层  风格 S                    「我在这个语境里借用的表达语言」  公共、可换、可丢
─────────────────────────────────────────────────────────────
输出     R(x | c, p) = σ( (w_pop + Δ_c + δ_p) · φ(x) )
```

三条可检验的断言：

1. **内核可迁移**：在领域 A 学到的 `δ`，对领域 B 的判断有正的预测增益。没有增益就不是内核，只是风格偏好。
2. **内核可压缩**：能用 5–9 条人话（`kernel_claim`）表达，且每条都带反例。
3. **内核可反驳**：新证据能让它改变；改不动的不是内核，是信仰。

一句诚实：**不是每个人都有稳定的内核**。实测模拟显示，40 次比较足以画出轮廓（与真值相关系数 ρ≈0.44），要到 ~160 次才谈得上"可断言"（ρ≈0.75）。所以产品必须分级说话，而不是第一周就给用户发一张"你的美学人格"证书。

## 1. 为什么个人内核是正确单位

| 方案 | 它会变成什么 | 问题 |
| --- | --- | --- |
| 单一大众模型 | 一个永远正确的中间值 | 所有人得到同一套建议，AI 设计同质化的根源 |
| 按人群细分（性别/年龄/地区） | 又一组刻板印象 | 把个体塞进更大的盒子，盒子还是盒子 |
| 纯个人偏好模型（只看点赞） | 信息茧房 | 只学到"我见过的"，学不到"我还没见过的" |
| **个人内核 + 公共风格库** | 判断归个人，语言归公共 | 需要区分"哪个成分是内核、哪个是风格" |

关键区分：

- **内核**回答「我为什么觉得美」——这是判断，跨媒介稳定；它会拒绝某些东西（负向约束往往比正向偏好更稳定）。
- **风格**回答「我用哪种语言表达」——瑞士网格、侘寂、粗野主义都是语言，可以今天用明天换，不影响你是谁。

产品逻辑因此只有一句话：**内核做硬约束，风格做软建议。**

## 2. 内核的可测定义

### 2.1 层级效用模型

```text
R(x | c, p) = w_pop · φ(x)  +  Δ_c · φ(x)  +  δ_p · φ(x)
              └ 人群先验 ┘    └ 语境偏移 ┘    └ 个人内核 ┘

φ(x)  作品的基元得分向量（38 维，来自观察与度量）
w_pop 从联邦判定聚合的先验
Δ_c   语境（领域/媒介/年代）偏移，人人不同
δ_p   个人内核：跨语境保持不变的部分
P(a ≻ b) = σ(R_a - R_b)
```

> 与主设计 §2.2 的关系：四成分响应模型（秩序/工艺/新意/张力）解释"**为什么**美"，这里的层级线性模型是它的**局部线性近似**，负责"**谁**更喜欢**哪一点**"。`φ(x)` 里既含 38 个基元得分，也含 C/K/n/t 四项的估计；线性化只是为了能从成对比较里稳定地估参数。

`δ_p` 稀疏（实测模拟中 5–6 个基元就能解释大部分个人差异），这很重要：

- 稀疏 → 几十次比较就能估出方向；
- 稀疏 → 能翻译成人话；
- 稀疏 → 跨域迁移有东西可迁。

### 2.2 内核度（kernelness）

```text
kernelness_p = 个人可预测增益中，由 δ 解释的比例
             = 1 - Var(Δ_c) / Var(Δ_c + δ_p)
```

- 接近 1：你的品味是"跨媒介的统一判断"（喜欢巴洛克的人，做界面也偏重层次与装饰）。
- 接近 0：你的品味是"分领域的"（海报要极简，界面要信息密集，并不矛盾）。

**低内核度不是缺陷。** 引擎应该说"你的品味按领域分叉"，而不是硬凑一个人格。这是本设计与其他"审美人格测试"最大的区别。

### 2.3 三条断言怎么验

| 断言 | 方法 | 通过标准 |
| --- | --- | --- |
| 可迁移 | 用领域 A 的判定拟合 δ，预测领域 B 的留出判定 | 相对先验有正增益（+3% 以上） |
| 可压缩 | 主张数 / 覆盖的判定比例 | ≤9 条主张，覆盖 ≥60% 的判定 |
| 可反驳 | 主动呈现与主张相反的作品，记录判定 | 用户接受修正的比例 ≥30% |

## 3. 学习：从 30 次比较到一个内核

### 3.1 拟合方式

- 目标：`max Σ log σ(y·δ·Δφ) - λ/2·||δ - 0||²`，L2 拉向人群先验（不是拉向 0）。
- 小样本（<60 对）时先验权重大，避免过拟合；样本变多后逐步放开。
- 每轮重拟合生成新 `kernel` 版本，旧版本保留，可以看到"我的口味怎么变的"。
- 不确定度用 bootstrap 或 Laplace 近似，输出到 `kernel_claim.confidence`。

### 3.2 主动选择比多问更重要（实测模拟）

模拟设置：38 维、600 件作品、真实内核稀疏 6 维、人群先验 N(0,0.3)、判定从 sigmoid 采样（自带噪声）、15 个随机种子取均值。对比"随机选对"与"按不确定度 × 特征差选对"。

| 比较次数 | 方式 | 留出准确率 | 先验基线 | 理论上限 | 与真值 ρ |
| --- | --- | --- | --- | --- | --- |
| 20 | 随机 | 0.596 | 0.594 | 0.709 | 0.24 |
| 20 | 主动 | 0.606 | 0.588 | 0.711 | 0.35 |
| 40 | 随机 | 0.617 | 0.595 | 0.712 | 0.38 |
| 40 | 主动 | 0.616 | 0.585 | 0.707 | 0.44 |
| 80 | 随机 | 0.639 | 0.600 | 0.715 | 0.51 |
| 80 | 主动 | 0.638 | 0.591 | 0.713 | 0.61 |
| 160 | 随机 | 0.655 | 0.596 | 0.711 | 0.64 |
| 160 | 主动 | **0.668** | 0.591 | 0.717 | **0.75** |

三个必须写进产品的结论：

1. **先验很强**：不做任何个性化，人群先验已经有 0.59 的准确率。个性化的增量是 +0.03 ~ +0.08，不要吹成"读心"。
2. **主动选择约 1.4–1.7 倍样本效率**：主动 40 次（ρ=0.44）≈ 随机 57 次；主动 80 次（ρ=0.61）≈ 随机 137 次（按相邻点线性插值）。提升真实但有限，别把它当卖点。
3. **准确率不是价值，主张才是**：准确率的边际收益很小，但 δ 的方向一旦稳定，就能翻译成"你在张力上比人群高 1.2σ"这种可执行、可反驳的话。**个人模型的价值在解释与跨域，不在分数。**

**在真实语料上的复演（2026-11-10，Rust 原型）**：用 810 件真实作品的 6 维像素代理特征重跑，同样的合成判定流程得到——n=200 时留出准确率 0.775–0.875、与真值 ρ=0.91–0.98；n=40 时 ρ 在 0.47–0.97 之间波动。对比随机与主动选择：**在只有 6 个有效维度时两者差异落在噪声内**（n=40 与 n=200 均如此），主动选择的收益主要出现在高维、先验弱的场景（上面 38 维模拟）。所以：保留主动选择，但不要把它写成卖点；真正决定体验的是**维度数量与题目质量**，不是选择算法。

### 3.3 成熟度阶梯（决定产品能说什么）

| 级别 | 判定数 | 已知 | 允许输出 | 禁止输出 |
| --- | --- | --- | --- | --- |
| L0 | 0–19 | 只有轮廓 | ≤3 条弱主张，标"探索中" | 任何人格标签 |
| L1 | 20–59 | ρ≈0.44 | 5 条主张，confidence < 0.6 | tradeoff、signature |
| L2 | 60–149 | ρ≈0.55 | tradeoff、floor | 跨域断言 |
| L3 | 150+ | ρ≈0.75 | signature、跨域断言 | 无（仍带置信度） |

### 3.4 主动学习的出题规则

`pair_task` 的候选人由四个目标轮流产生，防止只问"最不确定"而牺牲覆盖面：

| purpose | 规则 | 占比 |
| --- | --- | --- |
| `kernel` | `P·(1-P)·||Δφ||` 最大（信息量最高） | 50% |
| `coverage` | 当前 δ 置信度最低的基元，配一件高实现度作品 | 25% |
| `style` | 同内核不同风格的两件作品（测风格是否影响判断） | 15% |
| `consistency` | 重复出现过的对（测可靠性，不计入内核） | 10% |

跨域早期就要掺进去：如果前 20 组全是界面，你永远发现不了内核是否跨域。

## 4. 内核卡

内核卡是产品的核心物件——**一份可以拒绝的自我描述**。

```text
┌ 你的美学内核 · L2 · 更新于 11-10 ─────────────────────┐
│ 偏好  你在「张力」上的偏好高于人群 +1.2σ  (conf 0.72) │
│ 偏好  你偏爱「唯一例外」：规则里只留一处破格 (0.68)   │
│ 取舍  留白 > 信息密度：两者冲突时你选空  (0.61)       │
│ 门槛  工艺低于 78 分位的作品你几乎不选  (floor)       │
│ 拒绝  装饰性渐变、拟物阴影  (3 次反例一致)            │
│ 签名  单一强调色 + 一处破格，跨界面与海报都成立 (0.66)│
│ ───────────────────────────────────────────────────── │
│ 不确定：你在「材质对比」上还没有稳定判据              │
└───────────────────────────────────────────────────────┘
```

五类主张对应 `kernel_claim.kind`：

| 类型 | 含义 | 证据要求 |
| --- | --- | --- |
| `prefer` | 相对人群的偏好偏移 | ≥8 次判定 + 效应量 > 0.5σ |
| `avoid` | 稳定拒绝 | ≥3 次反例，且无反证 |
| `tradeoff` | 两个基元冲突时的选择顺序 | 需要成对冲突样本 |
| `floor` | 不可妥协的门槛 | 需要阈值附近的样本 |
| `signature` | 跨领域都成立的手法 | ≥2 个领域的证据 |

防巴纳姆效应：内核卡必须包含**至少一条不确定**与**一条可被拒绝的强主张**。只写"你欣赏平衡与和谐"的卡片，任何人都能认领，等于没有信息。

## 5. 风格层：内核之外才是风格

- `style` 是公共对象：可以来自历史流派（瑞士国际主义、侘寂）、平台习惯（Material、Cupertino）、或一群人的共识聚类。
- `style_work` 绑定典范作品（exemplar / variant / counter），让风格有证据而不只是形容词。
- `style_adoption` 是个人选择：`trial → active → dropped`，**不影响 `δ_p`**。
- 规格生成时两段式：

```text
[不可妥协] 来自 kernel_claim：floor、avoid、tradeoff
[可借用]   来自 style：具体的形式语言、配色、字阶、装饰
```

- 风格测试：同一件作品换三种风格，用户判定应当仍然符合内核（若不符合，说明那条主张其实是风格偏好，要降级为 `style`，从内核里删掉）。这个测试叫**换皮测试**，是区分内核与风格的唯一硬手段。

## 6. 参与：个人判定如何汇成公共共识

每个人都能参与评定，但有三种可见性，默认最保守：

| visibility | 含义 | 用途 |
| --- | --- | --- |
| `private`（默认） | 只在本机 | 训练自己的内核 |
| `federated` | 上传"作品对 + 结果 + 反应时"，不上传图片与自由文本 | 聚合人群先验 |
| `public` | 明确公开，可与他人比较 | 分歧地图、社区榜 |

隐私与治理：

- **本地优先**：图片、截图、自由文本永不出设备；只上传抽象判定。
- **k-匿名**：任何对外显示的聚合至少覆盖 30 人，否则只显示"样本不足"。
- **可撤回**：撤回同意后，后续聚合不再使用该用户数据（历史聚合不追溯，但要说明）。
- **可靠性**：`person.reliability` 由重复对一致率、反应时异常、直线作答共同决定，低可靠度的判定降权而不是拉黑。

公共层的三种产物：

1. **人群先验** `w_pop`：所有人共享；
2. **分歧地图**：你与多数人在哪些作品/基元上相反（`v_divergence`）；
3. **风格聚类**：把采用相似风格的三角洲聚成新的 `style`，但**不暴露任何个人**。

## 7. 产品形态（ToC）

每天 3 分钟，五个循环：

| 环节 | 时长 | 设计要点 |
| --- | --- | --- |
| 每日五组比较 | 90 秒 | 大图、二选一、无文字干扰；每天上限 12 组，防刷 |
| 一次微问 | 15 秒 | "为什么选这张？"三选一（更安静/更有力/更精致），只做归因辅助 |
| 内核卡更新 | 即时 | 有新主张时高亮，旧主张可"不认同"（进反例队列） |
| 审美体检（每周） | 3 分钟 | 分歧地图、领域分叉、稳定性曲线 |
| 风格试验场 | 自选 | 同一作品换风格，用于验证内核而非改变内核 |

反成瘾设计（不是道德洁癖，是产品定位）：不做好坏排行榜、不做无限滑动、不做连续打卡奖励。这个产品卖的是"想清楚自己"，不是"多巴胺"。

## 8. 数据模型增量

迁移脚本：[002-personal-layer.sql](inspiration/migrations/002-personal-layer.sql)（在 v2 上执行，`schema_version` → 3），已在 SQLite 3.54 实测建表、ALTER、视图与外键通过。

| 表/视图 | 作用 |
| --- | --- |
| `person` | 本地 UUID、同意项、可靠性 |
| `judgment_session` | 每次评定的会话（每日/深度/一致性/风格探测） |
| `judgment.actor_id / session_id / visibility / latency_ms` | 把已有的判定表升级为"谁的判定、在什么场景、是否上传" |
| `kernel` | 版本化的个人权重、先验、拟合指标、成熟度 |
| `kernel_claim` | 内核卡的五类主张，带效应量、置信度、反例 |
| `pair_task` | 主动学习的出题队列 |
| `style` / `style_work` / `style_adoption` | 风格层与个人采用关系 |
| `v_kernel_card` / `v_person_activity` / `v_divergence` | 卡片、活跃度、分歧 |

设计取舍：`judgment` 不加 `person_id` 之外的私有表，保证"同一张判定表既能训练个人也能聚合公共"；`visibility` 是列级开关，撤回同意只需改值 + 重算，不需要搬数据。

## 9. 服务接口

```sh
ie me init --name ...                      # 建本地人格，默认 private
ie judge --a 12 --b 30 --outcome a_wins    # 记一次判定（可批量导入）
ie next-pairs --n 5                        # 主动学习出题
ie kernel fit                              # 重拟合，产出新版本
ie kernel card --format md|json|png        # 内核卡
ie kernel diff --from 3 --to 4             # 口味变化
ie style list --domain ui                  # 风格库
ie style adopt swiss --weight 0.6          # 试用某风格（不动内核）
ie inspire --as me --to ui                 # 用「内核 + 风格」出灵感
ie consent revoke federated                # 撤回上传
```

DSH 接入：skill 增加一条——**生成前先读内核卡，把 `floor`/`avoid` 当硬约束，把 `style` 当软建议**。这样 AI 产出的东西会像"你"，而不是像"平均值"。

## 10. 评测

| 维度 | 方法 | 门槛 |
| --- | --- | --- |
| 个性化增益 | 留出判定 vs 先验基线 | +0.05 准确率或 ρ ≥ 0.5 |
| 内核稳定性 | 两周重测同一批对 | ρ ≥ 0.7 |
| 跨域迁移 | A 域学到的 δ 预测 B 域 | 正增益 ≥ 3% |
| 主张诚实 | 用户对内核卡认同度；对照卡（他人卡）认同度 | 认同 ≥70%，且显著高于对照（防巴纳姆） |
| 换皮测试 | 换风格后判定与内核一致率 | ≥75% |
| 隐私 | 出网流量审计 | 无图片/文本出网 |
| 留存 | D7 | ≥30%（3 分钟/天） |

## 12. 风险

| 风险 | 表现 | 对策 |
| --- | --- | --- |
| 早期过度断言 | 第一次用就告诉你"你是极简主义者" | 成熟度阶梯 + 强制不确定项 |
| 口味固化 | 推荐只给已喜欢的，越用越窄 | 15% 探索位 + 分歧地图 |
| 审美极化 | 用户被推向某个风格阵营 | 风格层可换 + 跨域样本 |
| 小样本噪声 | 50 次比较被当成定论 | 置信度 + 拉向先验的正则 |
| 操纵 | 商家刷判定影响共识 | 可靠性降权 + k-匿名 + 异常检测 |
| 隐私 | 图片/截图泄露偏好 | 本地优先 + 只上传抽象判定 |
