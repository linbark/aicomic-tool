## 不要做什么
- 不要让背景出现任何纹理或渐变，必须保持 #FBFAFB 的纯净度。
- 不要让所有图标都处于清晰状态，必须严格区分前景焦点与背景虚化层。
- 不要让鼠标指针的尺寸超过主体图标的 1/4，以维持视觉层级。

## 可迁移原则
- 当需要强调主体时，做背景虚化处理，因为景深差异能有效引导视觉焦点。
- 当画面元素较多时，做统一的几何形状约束，因为形状的一致性可以降低视觉复杂度。
- 当背景明度极高时，做深色主体对比，因为高明度对比能增强画面的通透感与现代感。

## 变体方向
- 保留散点布局，改成抽象的几何图形而非国旗。
- 保留景深虚化，改成垂直堆叠的列表式构图。
- 保留蓝色主色调，改成深色模式（背景 #114882，图标改为亮色）。
