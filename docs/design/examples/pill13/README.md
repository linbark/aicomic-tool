## 规格缺口清单（实现时不得不自己拍板的）

这是这轮最重要的产出：**规格没管、但实现必须决定**的东西。

1. **版式骨架是无效值**：简报写「以 33% 的版式骨架搭结构（COOLEST）」，`COOLEST` 是作品名不是结构。
   我只好自己定：单列主视觉 + 两段三栏网格。
2. **字号比例不可执行**：「标题:正文 = 1.5:1」不构成层级（正常 3–4×）。我用了 72/18 = 4×，超出规格。
3. **间距无值**：只说「输出间距」，没给模数。我自定页边 40、段距 88、行高 1.65。
4. **字体只有形容词**：「几何无衬线」没有字重/字距。我自定 600 字重、-0.03em 字距。
5. **颜色没有角色**：药液只有 HEX + 占比，没说谁是文字色、边框色、强调色。我按占比推断。
6. **组件状态全缺**：hover / focus / disabled / 响应式断点（我自定 820px）都没有规格。
7. **禁忌语境错配**：「禁止把背景线稿的留白填满」「不要加投影让头像与背景分离」——来自另一件肖像类作品，
   与落地页毫无关系。配方跨材料取药时，禁忌没有跟随语境。
8. **文案从零编**：规格不含内容，产品名、主张、数据（0.4%、8 秒）都是我编的。

## 每条缺口对应的改进

| 缺口 | 该改哪里 |
| --- | --- |
| 1 版式无效值 | `t.layout` 提示词禁止写作品名；`structure` 限定为枚举（单列/两栏/网格/散点） |
| 2 字号比例 | `t.type` 要求给「基准字号 + 级数 + 每级倍数」，不给单一比值 |
| 3 间距无值 | 新增 `t.spacing` 药液维度，输出模数与档位 |
| 4 字体无参数 | `t.type` 增加 weight / tracking 字段 |
| 5 颜色无角色 | `t.palette` 输出 role（bg/text/muted/border/accent） |
| 6 组件状态缺失 | 新增 `t.states` 药液维度（hover/focus/disabled/空态） |
| 7 禁忌错配 | 配方取药时按语境匹配；`formula` 的 inputs 需带 domain/page 标签 |
| 8 文案缺失 | 配方增加 `content` 槽位，或要求生成器明确标注「文案为占位」 |

前 6 条都是**药液维度缺失**，不是模型能力问题——这正是炼丹模型该继续扩的地方。
